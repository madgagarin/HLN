## 2. Lockfile Specification: `hln.lock`

Execution invariant: **"SemVer version ranges die at `hln lock`."**  
Runtime components NEVER resolve version ranges dynamically at execution time. All dependencies MUST be frozen in `hln.lock` with cryptographic hashes.

## 4. Deterministic Bundling Specification (`.tar.zst`)

To guarantee bit-for-bit reproducibility across diverse build environments and operating systems, bundles MUST be constructed following these deterministic rules:

1. **File Ordering:** Tar archive entries MUST be sorted lexicographically by UTF-8 byte path.
2. **Metadata Normalization:**
   * File timestamps (`mtime`) MUST be normalized to Unix epoch `0` (or the git commit timestamp).
   * User ID (`uid`) and Group ID (`gid`) MUST be set to `0` (`root:root`).
   * File permissions MUST be normalized to standard POSIX permissions:
     * Regular files: `0o644` (or `0o755` if executable).
     * Directories: `0o755`.
3. **Exclusions:** `.git`, `__pycache__`, `.pytest_cache`, `.venv`, and `*.pyc` MUST be strictly excluded.
4. **Compression:**
   * Zstandard (RFC 8878) compression.
   * Compression Level: 19.
   * Single-threaded (`threads=1`) to prevent nondeterministic chunk boundary interleaving.
