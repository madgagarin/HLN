# Contributing to HLN Specification

HLN is an open architectural standard. We welcome feedback and proposals.

## How to Contribute

1.  **Open an Issue**: Start by opening an issue to describe the change, addition, or correction you have in mind.
2.  **Discuss**: Align with the maintainers on scope and wording before writing the change.
3.  **Submit a PR**: Propose edits to the relevant document (under `spec/`, `schemas/`, `api/`, `MANIFESTO.md`, or a file under `concepts/`).

## Core Documents

-   `MANIFESTO.md`: The "Why".
-   `spec/`: Normative technical specifications (including `spec/SPECIFICATION.md`).
-   `concepts/`: Architectural and philosophical deep dives.
-   `schemas/` & `api/`: Machine-readable schemas and API contracts.
